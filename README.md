# GiT — Jadwal Sekolah PWA

Aplikasi jadwal sekolah yang bisa diinstall seperti APK di Android/iPhone.

## 🚀 Deploy ke Vercel (Recommended)

1. Upload semua file ini ke GitHub repo baru
2. Buka [vercel.com](https://vercel.com) → New Project → Import dari GitHub
3. Deploy otomatis! Selesai ✅

## 📲 Cara Install di HP

**Android (Chrome):**
1. Buka link Vercel-mu di Chrome
2. Tap ⋮ (titik 3) → "Add to Home screen"
3. Tap Install → muncul di layar utama!

**iPhone (Safari):**
1. Buka di Safari
2. Tap ⬆️ (Share) → "Add to Home Screen"
3. Tap Add
